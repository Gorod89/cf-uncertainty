# Sources of the article tables

Manuscript version v8; development commit `cfe956cd0ab4f157da27cf25156da0edc9643834`. For every table of the article: the files it was built from (SHA-256 of the file as published), the script that wrote the table and the command that regenerates its sources from the experiment artefacts. Paths under `results/report/` are the report assembly (`scripts/make_report.py`), paths under `results/controls/` the analysis tables of the control roots copied as they are. The compact tables of the article are assembled from these files by the manuscript's own table tool (`make_compact.py` / `make_c19.py`, kept with the manuscript sources, not in this repository); every number of a compact table is a cell or a rounding of the listed files. The model checkpoints are not published; the runs are regenerated by the commands of the README.
