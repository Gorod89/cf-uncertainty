# Sources of the article tables

Manuscript version v13 (public release v1.3.1). For every result table of the article: the files it was built from (SHA-256 of the file as published), the script that wrote the table and the command that regenerates its sources from the experiment artefacts. Paths under `results/report/` are the report assembly (`scripts/make_report.py`), paths under `results/controls/` the analysis tables of the experiment roots copied as they are (`results/controls/<root>/...` corresponds to `artifacts/<root>/...` of the development layout), and the per-profile platoon tables are in the release asset `e3_platoon_tables.tar.gz`. The compact tables of the article (`results/compact_tables/`) are assembled from these files by the published generators `scripts/compact_tables/make_compact.py` (c1-c18) and `make_c19.py` (c19), see `scripts/compact_tables/README.md` for the artefact layout they read; every number of a compact table is a cell or a rounding of the listed files. The model checkpoints are not published; the runs are regenerated by the commands of the README, and the trained checkpoints are the release asset checkpoints.tar.gz. The descriptive tables of the article (data sets, models, control design, protocol status, closest prior work) are written by hand from the configurations and the design document and are not listed here.
